# Changelog

## 0.1.0-beta.1 — 2026-10-14

- Første installerbare GymNotFound-beta for issue #1 og docs/10–11.
- 36 redigerte maler på norsk og engelsk; 30 fungerer uten sted, vær eller API. Hjem, hverdagsanker, ute, utforsking, praktiske oppgaver og frivillig selskap bruker samme motor.
- Tid, overskudd, gratisvalg, miljø, aktuelle værdata, ekte stedstreff og lagret feedback styrer ett forslag. «Ny idé» reduserer repetisjon.
- Lokal, versjonert gjestelagring, egenrapportert historikk, JSON-eksport og bekreftet sletting. «Prøv» fullfører aldri en aktivitet.
- Valgfri NIM, tospråklig mobilflyt, synlig tastaturfokus, redusert bevegelse og selvstendig WordPress-appskall. Shortcode for vanlig sideintegrasjon.
- MET-serveradapter med cache og betinget revalidering; valgfri Geoapify med kryptert nøkkel, 24-timers område-cache og atomiske kvotetak. Google Maps åpnes med destinasjonen som ekstern URL.
- Admin for sideutkast, maler, språkinnhold, kilder, kvoter, status og eksplisitt kildetest. Øvelsesinstruksjoner krever dokumentert godkjenning av den eksakte innholdsversjonen; gjenkjente øvelsestermer utløser også porten.
- Lokal unit-, WordPress-, samtidighets-, sikkerhets- og Chromium-testing, faktisk WP-admin ZIP-installasjon og MET-livetest. Se testmatrisen for begrensninger og NOT RUN.
