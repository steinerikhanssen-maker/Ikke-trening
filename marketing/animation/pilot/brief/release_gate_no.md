# Kvalitetsport (må bestås før videoen kalles publiseringsklar)

P0-visuelt:
[ ] Alex er samme person og har samme klær i alle scener.
[ ] NIM matcher original design i 4.1 (silhuett, farger, antenne), ikke tilfeldig ny AI-figur.
[ ] Treet får INGEN tilfeldig sirkelformet overlay-munn; øyne og barkmunn sitter fast i barken.
[ ] Lag/seams er usynlige; ingen rektangulære klippflater eller transparente halo-kanter.
[ ] Minimum 3 meningsfulle spillhandlinger: NIMs plan, Alex går ut, tree reveal, Alex reaction.
[ ] Hand-/telefonkontinuitet, skygger og kameraretning fungerer.
[ ] Intet klipp er bare Ken Burns på et ferdig storyboard.

P0-fortelling:
[ ] En ukjent seer forstår konflikten og payoff uten forklaring.
[ ] Vitsen er ikke avslørt før treet åpner øynene.
[ ] Personen er ikke utpekt som dum/lat; vitsen ligger i NIMs finte.
[ ] Brandet er synlig før avslutningen i appgrensesnittet, og igjen til slutt.
[ ] Filmen gir mening uten lyd takket være korte, redigerte captions.

P0-lyd/teknikk:
[ ] Replikker faktisk fremført i egne stemmer, 100 % forståelige uten unaturlig TTS-hastighet.
[ ] Munnformer følger primær lydhandling; ingen konstant loopende munn.
[ ] Lyd er lisensiert/original, ikke klipper eller peaker.
[ ] 1080x1920, 30 fps, 12.0 s, H.264+AAC, yttersperre for UI.
[ ] Full MP4-avspilling er testet i vanlig telefonapp med lyd PÅ og AV.
[ ] Gjennomgå de første 2 sekundene i normal scroll-hastighet; test på minst 5 uten kontekst.
[ ] Rapporter FAIL/NOT TESTED ærlig; ikke lever «ferdig» kun fordi det finnes en MP4.

Gate: Hvis ett P0-punkt faller gjennom, returnér til rigg/animasjon og utbedre, ikke render hele 10-episoders sesongen.
